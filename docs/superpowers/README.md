# Historical designs and plans

The `plans/` and `specs/` directories preserve dated implementation decisions. They are historical references rather than up-to-date setup guides; many examples still use the old `f1rl` Python import root or describe proposed services that do not yet exist.

For **current** behavior use [development](../development/README.md), [architecture](../architecture/README.md), and [operations](../operations/README.md). Do not mass-replace historical import snippets, file names or diagrams: those passages document what was originally proposed.

This directory had 44 Git-tracked documents at baseline `b11a501`; see [snapshot inventory](../BASELINE-DOCUMENT-INVENTORY.json).
