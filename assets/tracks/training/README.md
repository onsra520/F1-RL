# Candidate training-side tracks

This directory is an organizational bucket for WP2 candidate assets. It is **not yet** the frozen scientific training split.

WP3 will explicitly designate the research train/held-out sets and enforce ID/world-hash disjointness. Until then, do not infer scientific split semantics from this directory name alone.

Current candidate tracks contribute straight, slalom, right-turn, and ramp/elevation geometry to the 12–16 m road-width and ~120–160 m authored-surface scale envelope used by WP1B.
