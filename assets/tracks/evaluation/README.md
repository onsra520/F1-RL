# Candidate evaluation-side tracks

This directory is an organizational bucket for WP2 candidate assets. It is **not yet** the frozen scientific held-out split.

WP3 will explicitly designate train/held-out membership and enforce leakage guards. Until then, do not infer final evaluation semantics from this directory name alone.

Current candidates contribute the opposite turn direction and offset-slalom geometry to the 12–16 m road-width and ~120–160 m authored-surface scale envelope used by WP1B.
